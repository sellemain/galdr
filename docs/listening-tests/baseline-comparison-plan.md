# Baseline Comparison Plan v0

This is the first reusable comparison plan for perception-first work.

## Goal
Create a stable before/after lane so metric work can be judged against heard reality instead of only internal plausibility.

## Initial slices
1. **Tempo ambiguity regression**
   - Primary case: CIPHER THEY KNEW
   - Question: does galdr still present ~92 BPM as plain truth, or does it surface the ~140-142 BPM candidate honestly?
2. **Loudness / breath honesty**
   - Pick one compressed high-pressure track and one quiet-but-intense track
   - Question: does perceived pressure separate from simple energy better than the current baseline?
3. **Silence recovery**
   - Pick one track with meaningful departure and forceful return
   - Question: does the report describe re-entry shape rather than only flagging silence spans?

## Comparison shape
For each slice:
- save the baseline note using `template.md`
- keep the same track and command path across before/after
- quote the exact field(s) that drove the decision
- prefer one strong example over a vague corpus claim

## Naming
Use file names like:
- `tempo-cipher-they-knew.md`
- `lufs-breath-compressed-vs-quiet.md`
- `silence-recovery-helvegen.md`

The note should stay small. The point is reuse and honest evidence, not literature.
